# Footstep Dust Particle System

Handler 8 (FUN_801b2970) renders the footstep dust puff: a small upward burst of particles at each step of a unit walking on natural/rough terrain. It is triggered by the movement path, not by SEQ opcodes — the footstep particle dispatcher (FUN_8006ba38) reads the tile's surface type through a 46-entry jump table at 0x80067320 and allocates anim type 0x09 (natural) or 0x0F (hard/constructed). Spawning is gated by a null-pointer guard on the unit's +0x134 ability-data pointer, which is only ever set during ability execution and never cleared, so the dust only appears after the first ability use of a battle. Its config 6 (0x801b8678) uses SCATTER mode with zero position scatter, which triggers the shared zero-delta fallback (velocity (0, −5376, 0) = speed << 3 straight up), partially counteracts gravity with an upward weight (−512/−496), ignores the element byte (hardcoded CLUT 0x7AC9), plays no sound on init, and terminates one frame after the last particle dies via the shared fade_counter XOR-1 trick. godot-learning mirrors the config 6 data (`emitters.json` index 6, `HANDLER_CONFIGS[8] = [6]`, fixed palette 9) but does not implement the zero-delta fallback and no gameplay trigger plays handlers 8/9 on unit steps.
