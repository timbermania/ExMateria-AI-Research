# E001.BIN Memory Mapping

E001.BIN, the Cure effect's static definition file (44,868 bytes), is loaded into the effect file buffer starting at 0x801C2500, where the buffer carries a 4-byte size prefix and the file's header begins at 0x801C2504. Its header maps nine sections (frames, animation, script, particle-system data, animation table, effect flags, timeline, sound definitions, textures) and the file configures a 7-emitter particle system with spherical spread, Target-parent / Parent-Particle-child anchoring, and on-death child spawning (five of the seven emitters are parents — E0, E1, E2, E4, E5 — with E1→E5 completing the chain), rotating Z base-angle sweeps on emitters 0/2/3/4, and non-zero spawn spread on emitters 0, 3, and 5. At runtime, EffectState instances (248 bytes each in the array at 0x801BF02C) connect to the loaded image through script_data_ptr, and the globals at 0x801BBF84/0x801BBF88/0x801BC0C8 track the effect-data and timeline sections. A 2026-04-16 field-by-field comparison of the seven emitters adds per-emitter start times (emitter 5 starts at frame 50), animation indices, motion types, enable bytes, color masks, start/end positions, and count fields; its ±X/±Y/diagonal spread values conflict with the 3D spread start/end values recorded from the complete emitter report (both marked CONTESTED). The 2026-04-16 working document gives conflicting E001 spawn times (timing section 0: emitter 0 at frame 10, emitter 1 at frame 25), recorded as a CONTESTED pair with the debug-guide start times.
