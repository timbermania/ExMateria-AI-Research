# TRAP Hit Effect Particle System

The TRAP "hit clouds" effect is the in-memory BATTLE.BIN particle system that plays when a generic attack lands: the PostGenericAttack hit-cloud spawner routes through charge_effect_handler_2 at 0x801b153c, which spawns two particle types — stationary element-tinted DUST smoke clouds and gravity-arced white FLASH sparkles — from the 0x2E-byte config table at 0x801b8564, runs the shared TRAP physics pipeline per tick, and drives the unit white-flash palette call inline (no reaction handler). It is a separate effect from the Charge+X charge VFX ([[TRAP Charge Particle System]], handler 6) but shares the particle pool, physics integration, sprite/animation data layout, and palette functions with the E###.BIN system.

## Points

- **Hit-cloud routing: the ability's PostGenericAttack (SEQ 0xFFDE) calls the hit-cloud spawner FUN_8006894c, which converts the ability element bitmask to element_index 0–8 (FUN_801adfac), allocates a charge-effect slot with animation_type = 7 (FUN_801adfec; function_id 2 via the animation-type→function_id map at 0x801b84DC / DAT_801b84dc), and dispatches to charge_effect_handler_2 at 0x801b153c, called once per tick; each tick it spawns DUST via FUN_801a7f5c(config 0) + FUN_801b0c88(0, element_index + 0x7AC0) and FLASH via FUN_801a7f5c(config 1) + FUN_801b0c88(1, 0x7ACA), then updates every live particle with FUN_801aa7dc.** — `[S·R] 2/3`

- **TRAP animation sequences: DAT_801b8320 is a u16 offset table (offsets relative to the table base) with 17 sequences; each sequence is u16 total_entries + N × (u8 duration, u8 frame_index), typically ending with a duration-0 hold entry. Dust = sequence 0 at 0x801b8342 (6 entries: frames 0–4 at 2 ticks each = 10 ticks, then hold frame 4); flash = sequence 5 at 0x801b83A2 (2 entries: frame 22 held 12 ticks, then hold). Per-tick, when frame_duration hits 0 the particle loads entries[seq_index], increments seq_index, and on seq_index ≥ total resets it to 0 and sets animation_complete — so a lifetime −1 dust particle dies after one full pass (return !animation_complete).** — `[S·R] 2/3`

- **The TRAP sprite table at DAT_801b7694 is [base_offset u16 = 0x0002][107 u16 frame offsets][packed sprite data]; each sprite definition is 0x1C bytes: sprite_word (bit 9 = semi-transparency, bits 5–6 = blend 0 = 50% / 1 = Add / 2 = Sub / 3 = Add25%), u0/v0/u_span/v_span bytes, then four i16 world-space quad vertices; all 107 framesets are single-frame. Horizontal/vertical flips come from byte wrap in the renderer — U1 = (U0 + u_span) & 0xFF, V1 = (V0 + v_span) & 0xFF — so u_span/v_span 0xE0 (= 256 − 32) flip a 32-px sprite; dust frames 1–3 are H/V/HV flips of the same 32×32 TRAP1 region (UV (8,120) / (39,120) / (8,151) / (39,151)).** — `[S·R] 2/3`

- **Texture page: TPAGE = (sprite_word & 0xE0) | 0x08 = 0x28 → 4bpp, VRAM X base 512, Y base 0, additive (ABR mode 1). TRAP1 is 256×144 px 4bpp occupying the bottom 144 rows of the 256×256 page (Y = 112..255), so raw frame UV Y 120..248 = TRAP1 rows 8..136; the Godot TGA places TRAP1 at row 0, so UV_Y_GODOT = UV_Y_PEX − 112 (the parser applies −112 and keeps raw UVs in `uv_raw`). In WEP.SPR, TRAP1 starts at file offset 0x10400: first 0x200 bytes = 16 sub-palettes × 16 BGR555 colors, then the pixel data; dust cloud at UV (8, 120) 32×32, flash sparkle at UV (128, 120) 8×8.** — `[S·R] 2/3`

- **The TRAP data baked into BATTLE.BIN is compiled E###.BIN effect data: the frames section (header at 0x801b7690, group_count = 1, then 107 × (4-byte frameset header + 24-byte frame)) and the halfword-offset animation table match the E###.BIN FRAMES/ANIMATION layouts byte-for-byte, and the runtime is the same — 0xCC-byte particle pool at DAT_801b9278, same physics integration, same frameset renderer and apply_unit_palette_effect. The 0x2E emitter config is a simplified, no-curve form of the E###.BIN 0xC4 emitter (same parameters, no start/end interpolation); script bytecode, timeline color/particle/sound/camera tracks, time scales, and sound definitions are replaced by hardcoded C handlers (hardcoded sound ids 0x6A, 0xDB, 0xDC, 0xB8, 0x28); the particle-system header becomes globals at DAT_801b8a40/DAT_801b8a4c (gravity, inertia, emitter_count); and the texture is separated out to the WEP.SPR TRAP1 section instead of being appended to the effect file.** — `[S·R] 2/3`
