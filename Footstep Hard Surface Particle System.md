# Footstep Hard Surface Particle System

Handler 9 (FUN_801b2a88) renders the footstep puff on hard and constructed surfaces: when a unit steps onto one of eight surface types (road, wooden floor, stone floor, roof, stairs, waterfall, river, lake), the tile-characteristics byte routes through the 0x80067320 jump table to anim type 0x0F, which dispatches handler 9 to run per-frame until termination. It is structurally the sibling of handler 8 (natural-terrain dust, config 6) but differs in two ways: config 7 (0x801b86a6) uses SPHERICAL_RANDOM velocity mode with positive downward weight (net +4912–5152/tick, ~40% stronger than config 6, so the puff is tight and ground-hugging rather than a floating vertical geyser), and — unique to handler 9 — a camera height offset recomputed every state-2 tick that overwrites the config's pos_scatter_y in place so the puff spawns at the unit's feet regardless of tile elevation. godot-learning mirrors config 7 (`emitters.json` index 7, `HANDLER_CONFIGS[9] = [7]`, fixed palette 11 = CLUT 0x7ACB) and implements the SPHERICAL_RANDOM branch, but no gameplay trigger plays handler 9 on unit steps and the camera height correction is absent.
